# Impact of Dietary Fatty Acids on the Postprandial Extracellular Vesicle Proteome

**Master's Thesis** *Master's Degree in Omics Data Analysis and Systems Biology.* *Universidad de Sevilla & Universidad Internacional de Andalucía*

---

## Scripts Overview

### Script I: Data Preprocessing and Preliminary Analysis

* Data loading and protein filtering.
* Data characterization and missing values imputation.
* Principal Component Analysis (PCA)
* Spearman correlation analysis.
* Dataset functional enrichment (Jensen Compartments).
* Z-Score normalization and heatmap generation.

### Script II: Clustering and Enrichment Preparation

* Data formatting and export for VSClust and Metascape.
* Visualization and plotting of Metascape enrichment results.

### Script III: Differential Abundance Analysis

* Differential expression analysis using linear mixed models (`limma`).
* Volcano plots generation.
* Visualization of specific functional enrichments.
